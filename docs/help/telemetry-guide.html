运行时遥测手册

谛听的遥测层通过 eBPF 采集主机运行时行为：网络连接、DNS 查询、权限敏感操作、命名空间行为。所有事件携带进程归属（pid/ppid/uid/comm/exe）与容器 ID，以结构化 JSON 输出，是威胁检测与告警富化的数据底座。

1. 开启方式

遥测默认全部关闭（关闭时探针不加载，对既有功能零影响）。编辑 baselines/default.yaml：

telemetry:
  network: true    # 网络连接事件 connect/accept/bind + 五元组
  dns: true        # DNS 查询事件（UDP 53，提取查询域名）
  privilege: true  # 权限与命名空间事件
sudo ./baseline-guard monitor -c baselines/default.yaml

2. 采集点一览

事件类型eBPF 挂点采集内容
network.connectkprobe tcp_v4_connect五元组（已知限制：入口源端口未分配，sport=0）
network.acceptkretprobe inet_csk_accept完整五元组
network.bindtracepoint sys_enter_bind监听地址/端口
network.dnstracepoint sys_enter_sendto查询域名 + qtype（仅 UDP 53）
priv.setuid / priv.setgidtracepoint sys_enter_setuid 系目标 uid/gid
priv.capsettracepoint sys_enter_capseteffective 掩码（尽力解析）
priv.ptracetracepoint sys_enter_ptracerequest 类型 + 目标 pid
priv.module_loadtracepoint module:module_load模块名
ns.mounttracepoint sys_enter_mount源路径/目标路径/fstype/flags
ns.unsharetracepoint sys_enter_unsharenamespace 类型（flags 解码）
ns.setnstracepoint sys_enter_setnsfd + nstype，目标 ns 尽力解析

容器归属：用户态解析 /proc/<pid>/cgroup，支持 docker / containerd / CRI-O，输出 12 位短 ID；宿主机进程不带 container 字段。

3. 事件格式

{"event_type":"network.connect",
 "network":{"dip":"104.20.23.154","dport":80,"family":2,"protocol":6,"sip":"0.0.0.0","sport":0},
 "process":{"comm":"curl","exe":"/usr/bin/curl","gid":1000,"pid":7722,"ppid":7713,"uid":1000},
 "ts":994815000579}

通用字段：event_type（类型）、ts（纳秒时间戳）、process（pid/ppid/uid/gid/comm/exe）、container.container_id（容器进程才有）。负载字段按类型分别为 network / dns / priv / ns。

4. 触发验证命令

curl -s http://example.com -o /dev/null        # network.connect（dport=80）
nc -lvnp 4567 & echo hi | nc 127.0.0.1 4567    # bind + connect + accept 三件套
dig example.com                                 # network.dns（domain=example.com）
sudo -u nobody id                               # priv.setuid（target_id=65534）
sudo modprobe dummy && sudo rmmod dummy         # priv.module_load（name=dummy）
sudo mount -t tmpfs none /tmp/mnt && sudo umount /tmp/mnt   # ns.mount
unshare -m true                                 # ns.unshare（flags 含 NEWNS）

自动化验收脚本（逐项 PASS/FAIL，可重复执行）：

sudo bash tests/integration/test_net_collection.sh        # 网络三件套 + 容器归属
sudo bash tests/integration/test_dns_priv_collection.sh   # DNS + 权限四类
sudo bash tests/integration/test_ns_collection.sh         # 命名空间三类

5. 已知限制

  • connect 事件入口时源端口尚未分配，sip/sport 为 0（后续 inet_sock_set_state 补强）；
  • DNS 仅采 UDP 53；TCP 53（大响应/域传送）不采；sendmsg 路径尽力支持；
  • capset 掩码解析尽力而为，失败时事件仍落（掩码字段为未知标记）；
  • 短寿进程容器归属可能省略（/proc 已消失，属正常场景）；
  • 遥测落库（事件总线 + SQLite 批量写 + 进程树富化）开发中，当前输出为 JSON 日志。

6. 内核兼容性

推荐内核 5.10+ / 6.x（BTF + ring buffer + BPF LSM 全原生支持）。4.18（RHEL8）/ 5.4（Ubuntu 20.04）各采集点的红黄绿结论与降级路径，见 采集点内核兼容矩阵。
