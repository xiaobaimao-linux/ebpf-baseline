## 3. 性能四指标最终结论（引用 D1/D2 报告，不重新测量）

| 指标 | 目标 | W3 基线 | W4 最终 | 判定 |
|---|---|---|---|---|
| 事件吞吐 | 10k/s × 5min 高优零丢失 | 高优被丢 15.6 万条 | 3 轮 5min 复跑对账误差均 0.000%（ring 扩 2MB 后 reserve_failed=0） | ✓ 达标（perf-tuning-w4d1.md R12） |
| 内存 RSS | ≤150MB | 252.5MB | 稳态 123.5MB / 30min 均值 122.3MB（队列槽位改按需 + malloc_trim） | ✓ 达标，余量 ~25MB（R13-1） |
| 常态 CPU | ≤3% 单核 | 3.48% | 1.15%（消费线程空闲指数退避 200µs→2ms） | ✓ 达标（R13-2） |
| 系统调用额外延迟 | P99 ≤5μs | P99 +34.6μs | 归因完成：调试计时代码（已修）+ 实时 wakeup 调度固有尾 | ✗ 未达，按 PRD 归因+降级记录收口（R13-3） |

四项三绿一降级。消费线程 10k/s 下 CPU ~31% 单核（余量 ~3.2×），为 D4 规则引擎预留了预算。

对齐 PRD 版本里程碑：AI 资产 = v2.0 M1-5/M2-5（docs/prd.md:178,:194）；规则包/CIS = M2-6（:195）；管理中心 = v2.0 M9（:317-333）+ 本地 API M7-2（:302）。

## 5. 速率结论

4 周节奏稳定在"每周 1 个主攻方向 + 还上周债"，平均每周交付 2.75 个计划项。偏差模式单一：**性能类工作持续低估**（W3 计划外的性能攻坚占了 W4 前 2 天），W5-W8 计划已按此把引擎/平台类任务的缓冲前置（W6 的 DSL v2 列为"按需"而非承诺项）。
